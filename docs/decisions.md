# Frontend decisions

- **B1 — Tooling, SPA mode, query client.** Test stack is vitest 4 + jsdom + Testing Library (`npm run test`), with `@vitejs/plugin-react` 5.2 (already installed, works with vite 8.1.5). TanStack Start 1.168.32 does not accept `defaultSsr` in `createRouter` (TS2353), so SSR is disabled with `ssr: false` on the root route (`createRootRouteWithContext` options) instead. The router's `QueryClient` uses `staleTime: 30_000`, `retry: 1` (replaced by the `ApiError`-aware retry in B3) and `refetchOnWindowFocus: false`. `SSRProvider` (Fluent) removed from the root; other Fluent usage stays until B20. `.env` is git-ignored; `.env.example` documents `VITE_API_BASE_URL`.
  - **Baselines (pre-existing skeleton, not fixed here):** `npm run lint` reports about 5.3k problems, almost all `prettier/prettier` "Delete ␍" CRLF line-ending errors on the imported files (5311 at the initial commit); `npx tsc --noEmit` reports 35 errors, all in `lcms-app.tsx`, `login-page.tsx`, `lcms-api.ts` (strictness flags such as `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`). B1 adds no new tsc errors. The edited lines in `router.tsx` and `__root.tsx` follow those files' CRLF endings, so they add a few of the same CRLF lint errors; new files (`vitest.config.ts`, `src/test/*`, `utils.test.ts`) lint clean.
- **B1b — Line endings normalised to LF.** Added `.gitattributes` (`* text=auto eol=lf`, binaries marked, lock files left untouched) and converted tracked text files to LF with no content changes. New baseline: `npm run lint` 143 problems (136 prettier formatting errors in skeleton files, 7 warnings), down from ~5.3k; `npx tsc --noEmit` still exactly 35 pre-existing errors (32 `lcms-app.tsx`, 2 `login-page.tsx`, 1 `lcms-api.ts`).
